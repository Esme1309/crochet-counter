# 🧶 鉤針圈數計算小幫手

這是我為了方便記錄鉤針編織進度，開發的網頁互動小工具！專為手機操作而設計，讓編織過程更順暢。

👉 **[點此直接開啟計算機](https://esme1309.github.io/crochet-counter/)** 

## ✨ 工具特色

*   **直覺操作：** 超大按鈕，邊拿毛線邊點擊也沒問題。
*   **自動循環邏輯：** 當「目前圈數」達到設定的「預計總圈數」時，再次點擊會自動重置為 1，不需要手動歸零。

# 🧶 Crochet Row Counter

This is an interactive web tool I developed to easily track my crochet progress! Designed specifically for mobile use to make the crocheting process smoother.

👉 **[Click here to open the counter](https://esme1309.github.io/crochet-counter/)**

## ✨ Features

*   **Intuitive Design:** Extra-large buttons make it easy to tap while holding your yarn and hook.
*   **Auto-Loop Logic:** When the "Current Row" reaches the target "Total Rows", tapping again automatically resets the count to 1. No manual reset needed!
